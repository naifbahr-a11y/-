# منصة القسم القانوني لمصرف الرافدين

نظام الجرد القضائي الرقمي — بروشور ترويجي للمنصة.

## فتح البروشور

افتح ملف **[index.html](./index.html)** في المتصفح لعرض الصفحة الترويجية بالعربية (RTL).

لا تعتمد الصفحة على روابط خارجية (CDN أو خطوط ويب أو أيقونات عن بُعد)؛ كل التنسيقات والأيقونات مضمّنة داخل الملف.
